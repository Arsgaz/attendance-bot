# План разработки Attendance Bot

## 1. Подготовка проекта

- Зафиксировать структуру DDD-слоёв и правила зависимостей.
- Настроить Poetry, Ruff, pytest и pytest-asyncio.
- Добавить конфигурацию из переменных окружения.
- Подготовить отдельные точки запуска Telegram-бота и фонового worker.
- Настроить структурированные логи и correlation ID.
- Добавить Dockerfile и docker-compose для локального запуска.

## 2. Доменная модель

- Реализовать сущность студента.
- Реализовать жизненный цикл регистрации внешнего аккаунта (`telegram`, `vk`).
- Реализовать сущность занятия с датой, порядком, предметом и подгруппой.
- Реализовать агрегат посещаемости.
- Реализовать заявку на использование `Б`.
- Зафиксировать статусы посещения и преобразование `+` в `✓` для таблицы.
- Разрешить постановку посещаемости без временных ограничений.
- Реализовать недельный лимит `Б`.
- Реализовать правила самостоятельного и административного изменения отметки.
- Добавить доменные события для регистрации, посещаемости и синхронизации.

## 3. База данных

## 9. Процесс использования `Б`

- Реализовано создание бессрочной заявки на конкретное занятие.
- Реализовать уведомление старосты о новой заявке.
- Реализовано подтверждение и отклонение заявки через меню старосты.
- Реализована проверка недельного лимита: не более трёх актуальных `Б` с понедельника по воскресенье.
- Реализован показ использованного и оставшегося лимита студенту.
- Реализовано освобождение лимита после замены или удаления `Б`, а также при наступлении понедельника.
